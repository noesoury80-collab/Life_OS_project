# Tempo — planning personnel

Première version d'une application web de planning personnel.

## Fonctionnalités actuelles
- Tableau de bord quotidien
- Matières et tâches personnalisables
- Priorités, durées, échéances et notes
- Génération d'un planning de tâches
- Vues jour et semaine
- Modification, report et validation des tâches
- Réglages du début de travail, du dîner, de la fin de journée et de l'objectif sportif
- Sauvegarde locale dans le navigateur (localStorage)

## Tester sur ordinateur
Ouvrir `index.html` dans un navigateur récent.

## Publier gratuitement avec GitHub Pages
1. Créer un dépôt GitHub public nommé `tempo-planning`.
2. Ajouter `index.html` à la racine du dépôt.
3. Dans Settings > Pages, choisir `Deploy from a branch`, branche `main`, dossier `/(root)`, puis Save.
4. Attendre la publication. L'adresse sera de la forme `https://TON-IDENTIFIANT.github.io/tempo-planning/`.

## Important
Cette première version enregistre les données dans le navigateur de chaque appareil. Elle ne synchronise pas encore les appareils et n'inclut pas encore la synchronisation de calendrier ni une IA en ligne. Ne publiez aucune donnée personnelle dans le code.
